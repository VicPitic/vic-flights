# Vic Flights

An interactive personal flight atlas inspired by `hackerhouses-globe`.

Live at [flights.vic.ceo](https://flights.vic.ceo), with a Netlify fallback at [vic-flights.netlify.app](https://vic-flights.netlify.app).

## What it includes

- 27 mapped flight legs across 13 journeys
- Separate arcs for connecting flights
- Future and year filtering with an accessible journey picker
- Route details limited to years and airport paths
- Filter-aware distance, country, and estimated airtime statistics
- Per-journey and per-leg distance and estimated airtime details
- A 2023 London flight alongside the rest of the archive
- Reduced-motion support and responsive mobile layout

## Run locally

```bash
npm install
npm run dev
```

Build for production with `npm run build`.
